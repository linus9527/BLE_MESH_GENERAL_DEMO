# 资方演示 Dashboard

这是一个不依赖真实串口和 Node-RED Flow 的交互视觉 Demo，用于确认首页信息密度、四传感器卡、页面与 Mesh JSON 映射、水位单位、可配置上下限、水阀自动/手动逻辑、确认弹窗和串口交互。

直接双击 `index.html` 可以离线打开。也可以在本机终端启动静态服务：

```powershell
cd node-red/demo
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

演示建议：

1. 展示 1920×1080 首屏的四张传感器卡。
2. 点击顶部“数据映射”，说明四张卡、状态、趋势、阈值和阀门结果分别来自哪个 JSON 字段。
3. 点击水阀卡“阈值设置”，修改下限和上限；可先输入无效组合演示前端校验，再保存有效阈值。
4. 点击“演示控制”，使用随当前阈值自动变化的低液位/保持区间/高液位快捷场景，观察自动开阀、保持和关阀。
5. 切换为手动模式，查看接管确认弹窗。
6. 手动打开水阀，查看安全确认、网关接受和节点确认。
7. 切换水位单位来源，展示数据包单位优先、unit code 映射与 Node-RED 默认单位回退。
8. 模拟网关断开或水位传感器离线，展示服务不中断和自动控制降级。

该 Demo 不写入真实串口，阈值只保存在当前页面内存。正式 FlowFuse Dashboard 2.0 版本应把阈值写入 Node-RED 持久化上下文或配置数据库，完整规则见 [`../../docs/dashboard-data-mapping.md`](../../docs/dashboard-data-mapping.md)。
